# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Piwero/tuk-tuk/security/advisories/new).
Do **not** open a public issue for an unfixed vulnerability — that publishes the
attack before a fix exists.

We aim to acknowledge reports within **3 business days**.

## Supported Versions

Only the latest version on the default branch receives security fixes.
