# Redesign mockups

Design references for the UI redesign specified in issue #427. Each image is
the proposed design for one screen; the current screens are in
`docs/assets/screenshots/`.

| Mockup | Proposed design | Current screen |
|---|---|---|
| `today.png` | Today with Overdue / Schedule / Anytime, the day rail and the simplified sidebar | `today.png` |
| `task-detail.png` | Task detail as property rows | `task-detail.png` |
| `focus.png` | Focus with presets and today's Tasks | `focus.png` |
| `mobile-today.png` | Today on a phone with the five-slot tab bar | `mobile-today.png` |
| `goals-habits.png` | Goal card with pace, and the Habits week grid | `goals.png`, `habits.png` |

The mockups are light-theme stills. The macOS window frame around some of them
is presentation only. One known difference from the spec: the Goal card mockup
omits the Obstacle, which the spec requires.
