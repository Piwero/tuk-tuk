# Assist runs locally, suggests only, and persists nothing

Two clauses below are superseded by
[0009](0009-assistant-cloud-chat-suggest-only.md), for the Assistant
surface only: inference is configured per feature rather than always
local, and open-ended chat and multi-step planning are no longer out of
scope. Suggest-only and persists-nothing are unaffected — 0009 strengthens
both. Assisted Capture, described below, is untouched and stays local.

AI features (the Assist family, v2) run against a local model via Ollama, proxied through the backend — no cloud inference, no API keys, no user data leaving the machine. Assist is suggest-only: every output is an ephemeral Suggestion rendered inline (ghost chips, proposed orderings) that the user confirms or discards; confirmed results are persisted through the existing REST endpoints, so there is no Suggestion entity, no lifecycle, and no schema change. When Ollama is unreachable or no model is installed, Assist surfaces simply do not render — the app never advertises AI it cannot deliver.

Considered and rejected: cloud APIs (stronger models, but wrong for a self-hosted single-user app holding personal data, and adds a billing/key dependency); act-with-undo autonomy (requires an action log and trust the product hasn't earned); a persisted suggestion tray (adds an entity and review-queue UX for no v2 payoff — revisit only if an audit trail of AI suggestions is ever needed).

Consequences: features must be specced against a ~14B-class quantized model (e.g. `qwen3:14b` on a 12GB GPU) — structured extraction, classification, and summarization are in; open-ended chat and multi-step planning are out. Assist endpoints are stateless (`POST /assist/*` returning drafts). Anything the model is bad at deterministically (date arithmetic, RRULE construction) is resolved in code from the model's extracted intent, never generated by the model directly. Assist must handle English and Spanish input; both are covered by the test suite, which constrains model choice to multilingual-strong models.
