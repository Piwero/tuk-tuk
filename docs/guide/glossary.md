# Glossary

⏱ 3 min read · Look up any word you see in the app

**Do this first:** press `Cmd + F` / `Ctrl + F` and search for the word.

## Tasks

| Word | Meaning |
| --- | --- |
| **Task** | One thing to do. |
| **List** | A collection of tasks. |
| **Folder** | Groups lists in the sidebar. Holds lists, not tasks. |
| **Section** | A stage inside a list. Also a column on the board. |
| **Inbox** | The default list. Can't be deleted. |
| **Smart List** | A built-in view: Today, Next 7 Days, All. Calculated, not stored. |
| **Tag** | A coloured label you can add to any task. |
| **Priority** | None, Low, Medium or High. |
| **Checklist item** | A line inside a task with its own tick box. Not a separate task. |
| **Reminder** | "30 minutes before" style alert on a task. Saved, not sent yet. |
| **Quick-Add** | The one-line box that understands `#` `!` `~` `@`. |

## Calendar

| Word | Meaning |
| --- | --- |
| **Event** | A Google Calendar item. Read-only in Tuk Tuk. |
| **Unscheduled** | Open tasks with no date, waiting to be placed on the calendar. |
| **Active hours** | Your usual working hours, shown taller in Week/Day view. |

## Habits and focus

| Word | Meaning |
| --- | --- |
| **Habit** | Something you repeat, tracked by daily check-ins. |
| **Check-in** | One day's progress on a habit. |
| **Target** | The daily amount for a count habit, such as 8 glasses. |
| **Streak** | Days in a row without a miss. |
| **Focus session** | One Pomodoro or stopwatch run. |
| **Timer** | A saved focus setup, such as "Deep work: 50 min". |

## Goals

| Word | Meaning |
| --- | --- |
| **Goal** | An outcome for the quarter. |
| **Key result** | A number that proves progress toward a goal. |
| **Score** | Average progress across a goal's key results, from 0% to 100%. |
| **Focused goal** | The one goal shown on your stand-up. |
| **Obstacle / If-Then plan** | What might stop you, and what you'll do when it happens. |
| **Stand-up** | Daily page: Yesterday, Today, Blockers. |

## AI

| Word | Meaning |
| --- | --- |
| **Assist** | Smart Quick-Add that turns free text into a draft task. |
| **Assistant** | Chat that plans your day. |
| **Suggestion** | Anything AI proposes. Nothing happens until you accept it. |
